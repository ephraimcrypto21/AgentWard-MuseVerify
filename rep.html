🛡️ AgentWard + MuseVerify

Zero-Trust Agentic Remediation Harness & Runtime Circuit Breaker Architecture

Status: Production Ready

🛡️ AgentWard

AgentWard serves as the ingress shield and runtime circuit breaker. It intercepts prompts before they reach the agent using Prompt-Guard-86M to detect indirect prompt injections, jailbreaks, and exfiltration attempts. At runtime, it monitors tool calls, enforces strict token-velocity limits, and executes an automated Workspace Rewind if a rogue subagent attempts unauthorized credential access or destructive system calls.

🔬 MuseVerify

MuseVerify acts as the isolated AST and behavioral triage engine. It fans out vulnerabilities into isolated git worktrees, synthesizes concrete verification test harnesses, and executes them inside zero-network Docker containers (`--network none`) on AWS Lightsail. It then gates candidate patches using Purple Llama CodeShield and cross-model consensus.

Complete 9-Stage Engineering Pipeline

Stage 1: AgentWard Ingress Shield

Complete

Establishes an SSH tunnel (port 8000) between Kali Linux and AWS Lightsail. Deploys the Prompt-Guard-86M FastAPI classifier to strip indirect prompt injections while preserving functional code bugs.

Stage 2: MuseVerify Worktree Fan-Out & Docker Sandbox

Complete

Creates isolated git worktrees for each vulnerability, synthesizes AST verification tests using Meta Muse / agy, and executes pre-patch tests inside zero-network Docker containers on Lightsail.

Stage 3: AgentWard Runtime Hooks & Rewind Circuit Breaker

Complete

Intercepts pre-execution tool calls. Enforces deterministic secret-exfiltration filters, destructive syscall checks, and triggers automated workspace snapshots (`.agentward_checkpoint`) for instant rollbacks.

Stage 4: Defensive Patching, Cross-Model Consensus & Code Shield

Complete

Synthesizes secure patches via Meta Muse / multi-provider router, validates syntax with AST, scans code via Purple Llama CodeShield, and cross-verifies patches with multi-model consensus.

Stage 5: Multi-Agent Batch Orchestrator

Complete

Binds Stages 1–4 into a master orchestrator (`main_pipeline.py`) equipped with concurrency controls to smoothly process multi-file vulnerability batches on Lightsail.
